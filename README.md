# Auth Clean Architecture (TypeScript) 🛡️

[![TypeScript CI](https://github.com/kiltro-dev/auth-clean-architecture-ts/actions/workflows/ci.yml/badge.svg)](https://github.com/kiltro-dev/auth-clean-architecture-ts/actions/workflows/ci.yml)

A robust authentication service implementing **Clean Architecture** principles in TypeScript.

## Key Features
- **Separation of Concerns:** Distinct layers for Domain, Use Cases, Interfaces, and Infrastructure.
- **Dependency Injection:** Making testing and mocking easy.
- **Strict TypeScript:** Highly typed codebase ensuring reliability.

## Quick Start
```bash
npm install
npm run dev
```
